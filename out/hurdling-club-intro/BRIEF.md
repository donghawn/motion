# 허들링 클럽 소개 — BRIEF v1

- 입력 확정: 2026-11-08 (Asia/Seoul), 사용자 응답 “기본값”.
- 목적: 처음 보는 사람이 스킬 탐색 → 미션 결과물 제출 → 검토·승인 → 내 자산 흐름을 이해하게 한다.
- 총길이: 20초. 이전 제안에 대한 사용자 기본값 선택으로 확정.
- 주 레퍼런스: `references/starling-main.mp4`. 보조 레퍼런스 없음.
- 출력: `docs/video.md` 서두의 16:9, 1920×1080, 30fps. 총 600프레임.
- 룩: `docs/video.md` 1–5장. 밝은 단색, 기존 Pretendard, 원본 제품 화면·부품, 밝은 로고 엔딩.
- 핵심 메시지 제안: “배움이 쌓여, 나의 자산으로” (`src/screens/05-assets.png`의 실제 문구).
- 제품 근거: `src/screens/02-skills.png`, `03-mission.png`, `04-approved.png`, `05-assets.png` 및 `docs/design.md` 6장.
- 제작 방식: 실제 화면으로 맥락을 보여주고 기존 HTML 부품을 확대해 행동·결과를 설명한다. 떠 있는 카드의 이동은 편집 연출이며 실제 앱 인터랙션으로 주장하지 않는다.
- 주장 범위: 제출 후 검토·승인 단계를 구분한다. 즉시 승인, 수익 보장, 임의의 신규 성과 수치를 표현하지 않는다. 화면의 예시 수익을 사용자 성과로 내세우지 않는다.
- 사운드 제안: 내레이션 없이 가벼운 리듬의 음악과 주요 전환·승인 효과음. 음원은 아직 확보하지 않았으며 유료 생성·구매는 포함하지 않는다. 사용 가능한 음원이 없으면 무음 상태와 그 이유를 알린다.
- 모션 기준: `docs/morion.md` 1–5장에 문서화된 새 후보. 기존 확정 토큰으로 호칭하지 않는다.
