# Black motion reel — v2 preview proposal

사용자 지시: OOS16 레퍼런스처럼 역동적이고 재미있게, 배경 검정. 기존 A안의 서비스 흐름과 20초는 유지. 새 구도·모션은 미리보기 검토 대상이며 최종 영상 승인으로 간주하지 않는다. 이전 소스와 기록은 versions/v1에 보존, video.mp4는 이전 버전이다.

주 레퍼런스: https://motionimo.xyz/video/oos-16-design-reel (Flatwhite Motion). Aside에서 Vimeo 1134110334의 프레임을 직접 확인. references/oos16의 시트가 관찰 근거. 기존 Starling은 카드 누적·읽기 정착만 보조.

구현 전 고정 항목 N=5:
- O1 0.2–1.4s: 단어별 누적 타이포 → S1 두 줄을 마스크로 시차 공개.
- O2 16.3–17s, 37–38s: 기기 각도·크기 전환 → S1 기울어진 전체 폰에서 카드 클로즈업, S2 큰 폰이 돌아 정착.
- O3 6–8s: 요소 모임·장면 재구성 → S1 부채꼴 카드가 모여 같은 방향으로 퇴장, S4 카드가 모인 후 실제 자산 화면으로 이동.
- O4 2–4s, 54–55s: 캐릭터의 포즈·배치가 만드는 재미 → S3 원본 펭귄 래퍼가 뛰어들어 정착. 원본 캐릭터 자체를 변형하지 않는다.
- O5 27s, 57s: 밀도·크기가 다른 구도 사이 컷 → 카드 클로즈업, 큰 기기, 중앙 승인, 자산 배열, 여백이 있는 로고 순으로 구도 차별화.

영상 바탕은 #000, 문구 #fff, 강조 #3759de. 기존 흰색 로고 variant 사용. 원본 UI 색은 유지. 새 제안 hero=156.8/190.4px (video-display ×2), 중간 제목=117.6/142.8 (×1.5), 본문42/67.2 유지. 큰 문구는 사용자 '더 역동적' 요청에 대한 이번 검토용 제안이며 원본 Figma 값이라고 주장하지 않는다.

타이밍은 morion.md의 .1/.2/.3/.4/.6/.8초, 기존 cubic-bezier 사용. 기기/카드 회전은 새 장면별 후보 ±4/8/12도, 카드 팬의 시각적 분리용이며 실제 3D 기기 원근을 주장하지 않는다. 공통 토큰으로 확정하지 않는다. 위치는 1920×1080 안에서 실제 442×896 폰, 350px 부품, 제목 폭으로 산정. 필요한 세부 정보는 2.8배 부품으로 읽힌다.

|구간|화면과 움직임|정착 후 읽기|
|---|---|---|
|0–4|큰 헤드라인·기울어진 폰 → 세 스킬 카드가 펼쳐짐 → 모여 퇴장|제목 1.4초, 카드 1.2초|

|8–12|검토를 거쳐 → 하드 컷으로 승인 완료·원본 캐릭터·승인 화면|승인 1.8초 이상|
|12–17|자산 카드 세 장이 쌓임 → 오른쪽 실제 자산 폰, 왼쪽 핵심 메시지|카드 1.2초, 마지막 메시지 1.8초|
|17–20|펭귄·흰색 로고·메시지 중앙 정착|1.8초 이상|

금지: 반복 좌우 슬라이드 구성, 없는 UI, 임의 성과 숫자, 즉시 승인 주장, 가짜 3D 측면, 배경 그라디언트/입자/장식 링. 무음 미리보기(기존 BRIEF 대체 허용). 최종 렌더는 수정 미리보기 확인 후.

## 사용자 스크린샷 피드백 반영 — v2.1

사용자 요청으로 그라데이션 금지 항목을 해제. 검정 바탕 위 기존 브랜드 blue(#3759de)를 알파 .24 방사형/.14 선형으로 합성하는 정적 배경 제안. 원본 제품 UI는 변경하지 않는다. 설명 글자 42→61.6px, 행간67.2→89.6px. 엔딩 캐릭터는 승인 장면과 같은 perdi-flag 원본, 480×480.
미션은 2.6–2.8초 카드 퇴장 완료 후 2.8–3.0초 제출 버튼 진입으로 완전히 분리. 승인 설명은 1536px 폭, nowrap/keep-all을 명시해 한 글자씩 줄바꿈되는 현상을 방지. 공통 clip 래퍼에 inset:0을 지정해 절대 배치된 자식의 가용 폭을 확보.

### 상단 여백 수정
사용자 스크린샷에서 S1 카드 구간 제목이 상단에 붙는 문제 확인. 제목 축소 후 top=180-150=30px이던 위치를 180-40=140px로 변경. 첫 카드 기준 y340→380으로 내려 제목과 카드의 간격 확보. 다른 카드 위치·원본 내용 유지.

## 추가 사용자 피드백 — 레이아웃·크기·간격·버튼
- 자산: 반복 팬 배치를 폐기. 중앙 제목 + private-image 원본 카드 한 장(2.8배)을 읽힌 뒤 중앙 정면 폰(.8배)과 하단 메시지로 전환. 12–17초 유지. 카드 읽기 .7–2초, 전체 폰 2.8–4.6초.
- 미션: 카드 2.8→2.4배(약14% 축소), 기존 수평 중심을 유지하도록 x780→850. y340. 내부 원본 버튼 유지, 별도로 띄운 제출하기 버튼과 관련 동작은 사용자 요청으로 삭제. 카드를 장면 종료까지 유지.

## 순차 카드·미션 두 줄 — 최신 사용자 피드백
자산 카드는 같은 중앙 축(x470, 폭980)에 회전 없이 y330/560/790으로 배치. private-image(.1–.5s), review(.4–.8s), private-file(.7–1.1s) 순으로 아래에서 올라온다. 추가 두 카드의 시작 y는 프레임 아래1080에서 산정. 최종 카드 정착 후1.2초 유지, 2.3초부터 중앙 폰으로 연결. 최종 메시지는3.1–4.6초 유지.
미션 제목은 ‘미션에 / 적용하고’ 두 줄. 카드 배율2.4→2.0(추가 약16.7% 축소), x860/y460, 화면상700×506. 제목 끝415.6px과 카드 사이44.4px 확보. 사용자 지정 축소에 따른 부품 내부 작은 글씨는 보조 정보로 취급; 새로운 UI나 문구 생성 없음.

## 파란 강조 글자 가독성
사용자 요청으로 영상 전용 .blue 글자를 #3759de에서 #6685ff로 밝힘. 버튼·제품 화면·그라데이션의 브랜드 색은 유지. 원본 Figma 색 변경이 아닌 영상용 가독성 override.

## 자산 카드 입체감 — 사용자 요청
세 원본 카드의 내부 UI는 유지하고 외부 래퍼에만 CSS 3D 투영을 적용. perspective1200px, z=-90/0/80px, rotationX=8/6/4°, rotationY=-9/-6/-3°, x=-48/0/48px는 사용자 입체감 요청에 따른 새 장면별 연출 후보. 공통 원근과 얕은 각도로 글자를 읽을 수 있게 제한. CSS 변환과 GSAP 변환 중복 없음. 카드는 중앙을 기준으로 위에서 뒤쪽, 아래에서 앞쪽에 놓임. 기존 Shadow/lg(0 8 24 #0000001F)를 사용. 순차 진입 .1/.3/.5초, 각 .6초, 마지막 정착1.1초부터2.3초까지1.2초 읽기 유지. 2.3초에 깊이와 기울기를 정리하며 기존 중앙 폰으로 연결. 원본에 없는 실제 제품 3D 기능이나 인터랙션을 의미하지 않는 영상 연출.
