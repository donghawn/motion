# 허들링 클럽 모션 기준

성격: **경쾌함** — 사용자 선택. 빠르게 의도를 드러내고, 가볍게 정착한 뒤 읽을 시간을 준다.
레퍼런스: [Starling’s Motion Identity · Buff Motion / Brands In Motion](https://www.brandsinmotion.xyz/resource/buffmotion-starlingbank).
분석 대상: 페이지 첫 번째 메인 영상, `references/starling-main.mp4`, 640×360, 30fps, 약 74.83초. 시각 분석이며 음악·비트 동기화는 포함하지 않는다.
기존 기준: `docs/design.md`. 기존 모션 토큰은 없으므로 아래 이름과 수치는 모두 **새 후보**이며, 확정된 기존 토큰으로 취급하지 않는다.
색·폰트·문구·로고는 레퍼런스에서 가져오지 않는다. 장면 순서와 화면 배치는 영상별 비트 시트에서 정한다.
출처 기호 `R`은 관찰 구간이다. 제안값 옆의 `R`은 착안 근거이지 원본 프로젝트 설정값의 증명이 아니다.
프레임은 0부터 센다. 주요 구간은 2프레임 간격으로 비교했으므로 아래 관찰 경계에는 약 ±2f의 판독 오차가 있다.

### Duration 6단계 — 새 후보

30fps 기준 환산이며 다른 fps에서도 밀리초 길이를 유지한다. 숫자는 관찰 리듬을 실무용 눈금으로 정리한 제안이다.

| Primitive | 값 | 용도 | 근거와 제안의 관계 |
|---|---|---|---|
| `motion-duration-1` | 100ms / 3f | 요소 간 시차, 순간 반응 | R9의 짧은 누적 등장에 착안; 정확한 원본 stagger가 아님 |
| `motion-duration-2` | 200ms / 6f | 작은 강조, 빠른 퇴장 | R4의 약 6f 수축에 대응; R1·R2의 더 짧은 반응에도 적용 가능한 후보 |
| `motion-duration-3` | 300ms / 9f | 부품 등장, 상태 변화 | R6의 약 8f 확장을 9f로 정리 |
| `motion-duration-4` | 400ms / 12f | 컨테이너 확장, 화면 교체 | R5의 약 12f 확장에 대응 |
| `motion-duration-5` | 600ms / 18f | 시차가 있는 그룹 등장 | R3의 약 16f 이동·정착을 18f로 정리 |
| `motion-duration-6` | 800ms / 24f | 큰 화면의 초점 이동 | R8의 느린 이동에서 착안한 프로젝트용 후보; 원본 길이의 측정값이 아님 |

### 곡선 — 새 후보

영상에 곡선 그림은 보이지만 수치가 읽히지 않는다. 아래 cubic-bezier 제어점은 역산값이 아닌 재현용 제안이다.

| Primitive | CSS 값 | 적용과 근거 |
|---|---|---|
| `motion-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 빠른 진입 후 감속. R6 확장·정착 |
| `motion-ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 수축하며 빠져나가기. R4 |
| `motion-ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 같은 요소를 유지한 확장·초점 이동. R5·R8 |
| `motion-ease-settle` | `cubic-bezier(0.34, 1.3, 0.64, 1)` | 목표를 조금 지나 되돌아오는 정착. R3; 원본의 복합 궤적을 단순화한 후보 |

기본 곡선은 `motion-ease-out`. `motion-ease-settle`은 강조할 작은 요소의 transform에만 쓰며 opacity에는 쓰지 않는다.
이동 거리는 기존 `space-content` 또는 `space-large`를 부품 래퍼에 우선 재사용한다(`docs/design.md`의 16px·32px). 영상에서 측정한 거리가 아니다.
큰 화면 이동은 비트 시트의 시작·도착 위치로 계산한다. 임의의 고정 px나 회전 각도·확대율을 공통 토큰으로 추가하지 않는다.

## 2. Semantic

아래 5개는 새 후보. Pattern에서는 Primitive 숫자를 직접 반복하지 않고 이 조합을 참조한다.

| Semantic | Duration / 곡선 | 의미 | 레퍼런스 |
|---|---|---|---|
| `motion-enter` | `duration-3` / `ease-out` | 짧게 이동하며 등장하고 읽을 위치에 정착 | R3의 단일 부품 동작을 단순화 |
| `motion-exit` | `duration-2` / `ease-in` | 다음 정보를 위해 빠르게 축소하거나 이동해 퇴장 | R4 |
| `motion-change` | `duration-3` / `ease-out` | 같은 객체를 유지하며 상태·정보 영역 변경 | R6 |
| `motion-emphasis` | `duration-2` / `ease-settle` | 승인·성과·핵심 반응에 짧은 생동감 부여 | R1·R2; 회전은 선택적 연출 |
| `motion-transition` | `duration-4` / `ease-in-out` | 남겨 둔 요소를 연결점으로 화면 맥락 전환 | R5 |

표의 `duration-*`, `ease-*`는 각각 `motion-duration-*`, `motion-ease-*`의 축약 표기다.
하드 컷은 R10에서 관찰되는 편집 방식이다. 보간 애니메이션을 넣지 않으며 별도 Duration 단계나 Semantic을 추가하지 않는다.

## 3. Pattern

아래는 레퍼런스의 동작을 현재 자산에 옮기는 적용안이며 화면 배치나 장면 순서를 지정하지 않는다.

| 대상 | 재사용할 동작 | 토큰과 근거 |
|---|---|---|
| `src/parts/skill-card-{1,2,3}.html` | 카드별 등장 시점을 어긋나게 하고 마지막에 정착 | `motion-enter` + 시차 `duration-1`; 그룹 길이 `duration-5` 후보. R3·R9 |
| `src/parts/asset-card.html` | 카드 정체성을 유지한 상태 교체. 내용이 바뀌는 순간은 마스크로 가림 | `motion-change`; R6의 아이콘→정보 행 확장을 상태 교체에 응용 |
| `src/parts/mission-card.html` | 카드와 진행 정보를 구분해 등장. 진행 바는 실제 목표값까지 채움 | 외곽 `motion-enter`, 내부 `motion-change`; R3·R6에서 응용. 진행 바 자체는 직접 관찰 사례 아님 |
| `src/parts/badge-approved.html` | 승인 순간 짧게 확대·정착한 뒤 멈춤 | `motion-emphasis`; R1. 확대율은 새 후보로 남기고 임의 확정하지 않음 |
| `src/parts/button-submit.html` | 버튼 외곽을 유지하며 `data-state` 문구를 교체 | `motion-change`; R6에서 응용. 회전·바운스는 기본값에 포함하지 않음 |
| `src/parts/stat-card.html` | 카드 등장 후 수익 정보를 읽게 유지 | `motion-enter`; R6·R7. 숫자 카운트업은 직접 근거가 없어 기본 패턴에서 제외 |
| `src/parts/brand-icon.html`, `logo.html` | 현재 브랜드 자산을 래퍼로 등장·퇴장 | `motion-enter` / `motion-exit`; R3·R4의 일반 동작만 적용 |
| `src/screens/01-home.png`~`05-assets.png` | 화면 전체의 위치·크기·클립 영역으로 이동하거나 전환 | `motion-transition`; R5·R8. 화면 내부를 움직이려면 해당 HTML 부품을 별도 레이어로 사용 |

PNG 내부 요소는 독립적으로 움직일 수 없다. 원본 이미지를 잘라 늘이거나 그 안의 글자·아이콘을 변형하지 않는다.
부품 래퍼의 이동과 내부 상태 변화는 별도 타임라인으로 관리한다. 움직임의 목적이 같으면 같은 Semantic을 재사용한다.

## 4. 머무는 시간

머무는 시간은 등장 애니메이션이 끝난 뒤부터 센다. 지속시간과 읽기 시간을 섞지 않는다.

| 새 후보 | 값 | 사용과 근거 |
|---|---|---|
| `motion-hold-short` | `duration-5` = 600ms / 18f | 짧은 상태·아이콘. R7의 약 20f 정지 구간을 단순화 |
| `motion-hold-read` | `duration-5 × 2` = 1200ms / 36f | 제목과 짧은 설명. R7보다 읽기 시간을 늘린 제안으로 직접 측정값 아님 |
| `motion-hold-detail` | `duration-5 × 3` = 1800ms / 54f | 수치·상세 카드·화면. R7의 정지 원칙을 확장한 제안으로 직접 측정값 아님 |

실제 문구를 읽어 보고 부족하면 비트 시트에서 늘린다. 경쾌함을 이유로 읽기 시간을 줄이지 않는다.
마지막 항목의 등장·정착이 끝난 시점부터 그룹의 hold를 센다. 영상의 음악·컷 길이에 대한 수치는 여기서 확정하지 않는다.

## 5. 카메라

기본은 고정 카메라. 부품의 이동과 카메라 이동을 구분한다.
R8처럼 화면 전체의 초점을 옮길 때만 공통 래퍼에 이동·확대를 적용한다. 실제 3D 카메라 설정은 원본에서 확인할 수 없다.
새 후보 `motion-camera-focus` = `duration-6` + `ease-in-out`; 근거 R8. 이동량·확대율은 비트 시트에서 정하며 원본 수치로 주장하지 않는다.
카메라가 멈춘 뒤 상세 내용을 읽게 한다. 화면 내부 UI와 카메라를 동시에 크게 움직이는 방식은 기본 패턴에서 제외한다.
새로운 진폭·회전각·반복 주기·카메라 값이 필요하면 **새 후보**로 근거와 함께 제시하고, 기존 규칙으로 몰래 추가하지 않는다.
