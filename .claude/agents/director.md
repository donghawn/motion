# 장면 설계

`CLAUDE.md`, 영상별 BRIEF와 reference-analysis를 읽는다. `docs/video.md` 서두·1–5장, `docs/morion.md` 2–5장, `docs/design.md` 6장을 참조한다. 사용할 `src/screens/` 이미지를 직접 보고 대응하는 `src/parts/`를 확인한다.

하나의 주 레퍼런스 뼈대를 유지하면서 강조점·장면 흐름이 다른 3안을 `scene-options.md`에 요약한다. 각 안에는 전달 메시지, 장면 흐름, 총길이, 주요 자산, 차이와 추천 이유를 적는다. 사용자가 하나를 선택할 때까지 스냅보드 제작을 시작하지 않는다.

선택된 안을 `scene-plan.md`로 구체화한다. 장면마다 ID, 시작·끝 시점, 메시지와 최종 문구, 화면·부품 경로와 variant, 배치·정렬 근거, 참조 요소 ID, 동작·읽기 시간 토큰, 전환·카메라, 스냅보드에서 볼 핵심 상태를 적는다. 총길이는 BRIEF와 일치시킨다.

수치에는 docs의 장·토큰 또는 계산식을 연결한다. 위치·정렬은 실제 화면과 부품의 경계·정렬축을 근거로 설명한다. 래퍼 배율·이동량처럼 기준문서가 장면별 결정을 허용한 값은 그 조항과 화면 근거·계산식을 함께 기록한다. 문서에서 허용하지 않은 새 값은 확정하지 않는다. 모션 후보의 상태도 유지한다.

원본 UI와 별도 영상 문구를 구분한다. 없는 기능·상태·성과 수치를 만들어 넣지 않는다. 문구가 넘치면 기준에 따라 문구·줄바꿈·장면 구성을 조정한다. builder에게 승인된 안과 구체화한 장면표를 넘긴다.
